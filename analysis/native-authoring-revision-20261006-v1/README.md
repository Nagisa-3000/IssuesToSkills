# Exact-source native draft revision

This change repairs the native authoring recovery path. It does not establish WorkflowRewriter transfer, CrossBind utility, Ranker utility, Skill functional qualification, or formal SWE acceptance.

A complete rejected draft previously triggered another request for the entire bundle. Several models returned capacity or unresolved-validation deferrals instead of correcting the draft. Those original drafts, requests, failures and deferrals remain intact.

The revision caller reconstructs the exact original authoring request from current validated source bytes, the full original generation context, the accepted mechanism review, and historical source qualification. Any mismatch fails before a model request. Original extraction and recovery now share the same authoring payload builder, request builder and authority gate; complete native publication and Workflow coherence remain mandatory.

The model returns an exact-base-digest revision envelope containing complete replacements for existing allowed files. The host assembles those replacements unchanged. Provenance, Episode and evidence resources cannot change; no file additions/deletions, namespace changes or host-authored missing semantics are allowed. All untouched authored bytes are retained. Each attempt stores its exact request, base, response, assembled bundle, merge audit, validation failure and any context materialization. A failed assembled draft can become the next sealed base; it is never an admitted package. Author deferral is not an applicability negative.

Role diagnostics enumerate exact PatternRole.id/ActionContract.semantic_role and declared effect disagreements. Eval diagnostics enumerate missing boundary outcomes, Action coverage, setup/checks fields, duplicate cases and premature execution claims. PASS means declared-field consistency only. Diagnostics neither interpret nor execute checks.
